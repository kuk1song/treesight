# Security

Please report vulnerabilities in treesight privately, through "Report a vulnerability" on this repository's Security tab. Do not open a public issue.

Fixes go into the latest release only; update as the [README](README.md#install) says.

treesight reads your Claude Code session transcripts. If you find a way that text from a session could run as code in the page, reach the network, or leave secrets unmasked in the digest or the page, that is a security issue.

Problems in Claude Code itself go to Anthropic: see [anthropics/claude-code SECURITY.md](https://github.com/anthropics/claude-code/blob/main/SECURITY.md).
